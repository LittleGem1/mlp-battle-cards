MLP Battle Cards – Kartenrand + Artefakt-Seltenheit Fix

Diesen Patch NACH dem letzten MLP_ARENA_GOLDWAHL_SPECIALS_FIX einfügen.

ARTEFAKTE:
- Artefakte sind jetzt deutlich seltener im Goldstapel.
- Der Goldstapel hat weiterhin alle 3 Artefakte mit exakt derselben Chance.
- Es gibt KEINE feste Reihenfolge.
  -> Star Swirls Tagebuch kann zuerst kommen.
  -> Kristall Herz kann zuerst kommen.
  -> Elemente der Harmonie können zuerst kommen.
- In einer 2-Karten-Goldauswahl kann höchstens 1 Artefakt liegen.
- Sobald tatsächlich ein Artefakt gewählt/gefunden wurde, ist die NÄCHSTE
  Goldauswahl garantiert artefaktfrei.
- Erst danach können wieder Artefakte auftauchen.
- Ein bereits vom Spieler besessenes Artefakt wird ihm weiterhin nicht
  als nutzlose Goldauswahl angeboten.

KARTENOPTIK:
- 14 Spezialkarten mit auffällig großen schwarzen, randverbundenen Außenflächen
  wurden automatisch bereinigt.
- Nur Schwarz, das wirklich mit dem äußeren Bildrand verbunden war, wurde entfernt.
- Schwarze Bereiche INNERHALB des Kartenmotivs bleiben erhalten.
- Transparente Außenfläche wird sauber auf den Kartenrahmen zugeschnitten.
- Zusätzlich erzeugt das CSS selbst keinen schwarzen Karten-Hintergrund mehr.

Bereinigte Karten:
Tirek, Sludge, Diamond Dogs, Changeling, Nightmare Moon, Hydra,
Manticore, Timberwolves, Grogar, Daybreaker, Pony of Shadows,
Sunset Shimmer, Ahuizotl, The Mane-iac.

SPIELREGELN:
- Goldstapel-Erklärung auf „2 ziehen, 1 behalten“ korrigiert.
- Seltenheit, Artefakt-Cooldown und zufällige Artefakt-Reihenfolge ergänzt.
