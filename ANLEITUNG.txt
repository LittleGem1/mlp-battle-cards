MLP BATTLE CARDS – BECKY BAT + AUTOMATISCHE HOST-KARTENGALERIE V2
=======================================================================

NEU:
- Becky Bat ist eine SPIELBARE normale Karte: Stärke 6, Schnelligkeit 8,
  Magie 3, Energie 6. ID 107, Bild: public/assets/cards_new/107_Becky_Bat.webp
- Die bestehende Host-Kartengalerie fragt den Server bei JEDEM Öffnen neu.
- Im Server werden ZUSÄTZLICH automatisch Bilder aus diesen Ordnern erkannt:
  public/assets/cards/, cards_new/, specials/, specials_new/, artifacts/
- Bilder, die nur hochgeladen sind, aber noch keinen Eintrag in cards.js haben,
  werden als "nur Bildvorschau" angezeigt – noch NICHT im Spiel gezogen!
- Bereits in cards.js registrierte Karten bekommen weiterhin die echten
  Stats/Effekte, und die Galerie zeigt exakt ihre Spielbilder an.
- Die bestehende Host-Berechtigung bleibt serverseitig erhalten.

WICHTIG – ZU NEUEN KARTEN:
  Neue Bilder z.B. public/assets/cards_new/108_Mein_Pony.webp in GitHub
  hochladen -> GitHub Commit -> erfolgreichen Render-Deploy abwarten ->
  Lobby als Host neu öffnen -> Galerie erkennt das Bild AUTOMATISCH.
  Damit die neue Karte AUCH SPIELBAR wird, brauchst du weiterhin einen
  passenden Eintrag in cards.js, weil das Spiel Name und vier Werte
  nicht zuverlässig aus einer Bilddatei erkennen kann.
  Ein neuer Commit/Deploy ist notwendig: nur lokal auf deinem Computer
  abgelegte Dateien kann die Live-Webseite nicht sehen.

DATEIEN IN DIESEM ZIP (Pfad im GitHub-Repository)
  cards.js                      – Becky Bat als normale Karte
  public/assets/cards_new/107_Becky_Bat.webp – Bild von Becky Bat
  public/host_card_gallery.js   – aktualisiert bei jedem Öffnen
  host_gallery_autocatalog.js   – NEU im Hauptordner: Bilddateien erkennen
  server.js                     – OPTIONAL: vorbereitete Server-Datei
  public/host_card_gallery.css  – nur falls noch nicht vorhanden
  ANLEITUNG.txt                 – diese Anleitung
  SICHERER_CODE_PATCH.txt      – Änderungen für deine AKTUELLE server.js

EMPFOHLENER EINBAU – OHNE DEINE NEUEN SPIELFIXES ZU VERLIEREN
1. ZIP entpacken und deine aktuelle cards.js sowie server.js sichern.
2. public/assets/cards_new/107_Becky_Bat.webp zu GitHub hinzufügen.
3. In deiner AKTUELLEN cards.js nur Becky Bat ergänzen und den Pfad
   für neue Karten erweitern (siehe SICHERER_CODE_PATCH.txt).
   Nutze die beiliegende cards.js nur, wenn du sicher bist, dass seit der
   ursprünglichen Version keine anderen Karteneinträge hinzugekommen sind.
4. public/host_card_gallery.js ersetzen (nur die Galerie; Spielcode bleibt).
5. host_gallery_autocatalog.js NEU ins Repository-HAUPTVERZEICHNIS hochladen.
6. In der AKTUELLEN server.js NUR die drei Zeilen für das
   Host-Kartengalerie-Ereignis austauschen (siehe SICHERER_CODE_PATCH.txt).
   Bitte NICHT pauschal die beiliegende server.js ersetzen, wenn du später
   Änderungen an Würfel/Kristall/Specials/Artefakten/Host-Galerie gemacht hast!
7. Wenn die Galerie-Datei .css noch nicht vorhanden ist, hochladen.
8. Committen, Render-Deploy abwarten, Browser Strg+F5.

SO TESTEST DU ES
A) Als Host in die Lobby gehen -> "Alle Karten ansehen" -> nach Becky Bat
   suchen. Sie muss mit 6 / 8 / 3 / 6 erscheinen und als normal angezeigt werden.
B) Eine normale Karte ziehen -> Becky Bat kann (zufällig) im Stapel vorkommen.
C) Testweise public/assets/cards_new/108_Test_Karte.webp hochladen,
   OHNE cards.js zu bearbeiten -> nach Deploy in der Galerie als
   "nur Bildvorschau" vorhanden, aber NICHT im Ziehstapel.
   Die Testdatei danach wieder entfernen.
D) Galerie schließen und wieder öffnen -> Daten werden neu angefordert.

TECHNISCHER HINWEIS
Dieses Paket nutzt den bekannten Projektstand aus den bisherigen ZIP-Dateien.
Die gepackte server.js stammt aus dem früheren Galerie/Spiel-Fix. Bei einer
inzwischen neueren Live-Version bitte nur die kleinen Änderungen vornehmen.
Keine echte Live-Render-Partie wurde mit diesem Paket getestet.
