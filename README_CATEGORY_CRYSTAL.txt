GEÄNDERT:
- Die Kategorie-Münze wurde vollständig entfernt.
- Stattdessen erscheint ein vierseitiger, transparenter 3D-Kristall.
- Jede Seite trägt exakt eine Kategorie: Stärke, Schnelligkeit, Energie, Magie.
- Der Kristall wirbelt durch die Luft und landet exakt auf der serverseitig gezogenen Kategorie.
- Die sichtbare Vorderseite ist damit immer die tatsächlich gespielte Kategorie.
- Glas-/Kristallreflexionen, Lichtbrechung und Glanzanimationen sorgen für einen realistischeren Look.
- Münz-Klicks wurden durch Kristall-Klirren und einen deutlichen Landeton ersetzt.
- Es bleibt genau EINE Kategorie-Animation pro neuer Runde.
