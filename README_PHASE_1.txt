MLP Battle Cards – RELIKT-SYSTEM PHASE 1 (erste Hälfte)

Einfach den Inhalt in dein bestehendes Projekt kopieren und vorhandene Dateien ersetzen.

DIESE HÄLFTE IST ENTHALTEN:
✓ Neues Siegziel: Elemente der Harmonie + Kristall Herz + Star Swirls Tagebuch
✓ Zwei getrennte Ziehstapel
  - normaler Stapel nur für Charakterkarten
  - goldener Stapel für Spezialkarten + Artefakte
✓ Start: 6 normale Karten + 1 garantierte Spezialkarte
✓ Normale Karten können jetzt mehrfach im Match vorkommen
✓ Spezialkarten können mehrfach gezogen werden
✓ Nach jeder beendeten Runde gehen die ausgespielten normalen Karten zurück in den Kartenkreislauf
✓ Danach werden alle aktiven Spieler automatisch wieder auf 6 normale Karten aufgefüllt
✓ Kartenverluste wirken bis zum Ende der Runde; erst beim normalen Auffüllen kommt Ersatz
✓ Rundengewinner zieht danach automatisch 1 Karte aus dem Goldstapel
✓ Artefakte werden sichtbar beim Spieler gesammelt
✓ Eigene doppelte Artefakte werden nicht gehortet; sie werden zurückgemischt und neu gezogen
✓ Der Goldstapel enthält genug Artefakt-Kopien, damit auch bei 8 Spielern niemand dauerhaft blockiert wird
✓ Alle 3 verschiedenen Artefakte = Match gewonnen
✓ Neue Zieh-, Goldstapel- und Artefaktanimationen
✓ Eigene Sounds für Auffüllen, Goldziehung und Artefaktfund
✓ Finisher schicken die gespielten Karten jetzt zurück zum normalen Stapel statt zum Gewinner
✓ Kartenrückseite für Goldstapel/Artefakte eingebaut
✓ Spielregeln/Tutorial auf das neue Grundprinzip angepasst
✓ Aufgeben, Kreis-Anordnung, Mehrreihen-Hand und Zur-Lobby-Fix bleiben erhalten
✓ Würfel-Gleichstand zieht danach weiterhin eine andere Kategorie

NOCH NICHT IN PHASE 1:
– Die komplette Integration aller neu erstellten 20+ Spezialkarten
– Zielauswahl-Dialoge für Sludge, Bugbear, Ahuizotl, Lightning Dust, Mane-iac usw.
– Alle individuellen Spezialkarten-Animationen/Sounds
– Feinschliff des Trainings für jede neue Spezialkarte

Das ist absichtlich die zweite Hälfte, damit der neue Spielkern zuerst stabil getestet werden kann.
