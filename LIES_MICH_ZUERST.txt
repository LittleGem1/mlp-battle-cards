RENDER EINMALIG EINRICHTEN – UNBEDINGT NÖTIG
==========================================
1) Im Render-Dashboard eine PostgreSQL-Datenbank anlegen bzw. eine
   bereits bestehende langlebige Postgres-Datenbank verwenden.
   WICHTIG: Render Free Postgres ist KEINE dauerhafte Lösung,
   denn es läuft nach 30 Tagen ab. Wähle eine längerfristig betriebene
   Datenbank und sorge für Backups.
2) Datenbank und Render-Webservice möglichst in derselben Region.
3) Auf der Datenbank-Seite unter Connect die INTERNAL DATABASE URL kopieren.
4) Im Render-Webservice: Environment -> Add Environment Variable.
      Key:   DATABASE_URL
      Value: postgres://...  [hier die URL der Datenbank]
   KEINE echte URL oder Passwörter in GitHub hochladen!
5) Im Render-Webservice für Node als Build Command 'npm install' verwenden,
   damit das neue Paket 'pg' installiert wird (v.a. falls package-lock.json
   noch nicht aktualisiert ist). Start Command bleibt 'npm start'.
6) Patch-Dateien nach GitHub hochladen und Deployment abwarten.
   Die zwei Tabellen werden automatisch beim ersten Profilzugriff erzeugt.

BEDIENUNG FÜR SPIELER
=====================
- Beim ersten Laden wird automatisch EIN persönliches Profil erstellt.
- Bereits freigeschaltete Items und Rahmen aus dem bisherigen Browser
  werden EINMALIG in dieses Profil übernommen. Deswegen unbedingt das
  Update zuerst im bisher benutzten Browser öffnen!
- Danach sind die Server-Daten die Wahrheit; ein alter Browser-Cache
  kann den Serverbestand nicht zurücksetzen.
- Neben dem Spielernamen: 'Profil-Schlüssel sichern' anklicken.
  Den 64-stelligen GEHEIMEN Schlüssel sicher privat aufheben.
  Wer ihn kennt, kann das Profil übernehmen!
- Auf einem anderen Gerät 'Profil wiederherstellen' wählen und den
  gleichen Schlüssel eintragen. Gleiche Namen allein genügen nicht.
- Nach einem Match-Sieg bestimmt DER SERVER genau eine neue Freischaltung
  und schreibt sie EINMAL in Postgres. Das Geschenk zeigt danach die
  bereits gespeicherte Belohnung.
- Die drei ersten Items (Changeling-Flügel, Ballon, Süßigkeiten) und
  die zwei Start-Rahmen (Sakura und Candy) sind immer verfügbar.
- Bereits erhaltene Preise werden auf einem anderen Gerät angezeigt.
- Geladener Status: 'Rahmen & Items serverseitig gespeichert'.

WAS TUN, WENN NICHTS GESPEICHERT WIRD?
====================================
- Meldung 'DATABASE_URL fehlt': Datenbank nicht verbunden -> Schritt 1–6.
- Meldung 'pg' fehlt: package.json/Build Command prüfen.
- Meldung 'Profil nicht gefunden': NICHT einfach neuen Account erstellen;
  Profil-Schlüssel/Datenbank prüfen (z.B. abgelaufene Free-Datenbank).
- Darauf achten, dass die Datenbank selbst existiert und Daten aufbewahrt.
  Ein Update allein kann Serverausfälle, die komplette Löschung einer
  Datenbank oder verlorene Schlüssel nicht heilen.
