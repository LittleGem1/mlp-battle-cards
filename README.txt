Königin Chandra – korrigierter Einbau
====================================

Gewünschter Ablauf
------------------
1. ZUERST wird die normale Karte "Königin Chandra" wie jede andere Special-Karte angezeigt.
2. DANACH startet die Verwandlungsanimation.
3. DANN bleibt das zweite Bild (die finale Chandra-Karte) kurz stehen.
4. ERST DANACH darf der Spieler genau EINE Spezialkarte auswählen.

Wichtig
-------
- Es darf nur eine Spezialkarte gewählt werden.
- Keine normale Karte.
- Kein Artefakt.
- Die geheime Fähigkeit steht NICHT offen auf der Karte.

Einbau
------
1. public/queen_chandra_fx.js nach public/ kopieren.
2. Die Asset-Dateien in die angegebenen public/assets-Ordner kopieren.
3. Die Änderungen aus cards_patch.txt, server_patch.txt, client_patch.txt und index_patch.txt in dein Repo eintragen.
4. Danach neu deployen.
